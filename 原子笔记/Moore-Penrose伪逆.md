# Moore-Penrose 伪逆

## 一、详细讲解

### 1. 它解决什么问题

\(A\) 不是方阵或秩亏时没有逆，但人们仍需要一个“作用像逆”的矩阵：对任何 \(b\)，给出残差 \(\|Ax - b\|\) 最小、且自身范数最小的那个解。伪逆 \(A^+\) 就是这个标准选择。

### 2. 核心定义与形式

\(A^+\) 是满足四个 Penrose 条件的唯一矩阵：\(AA^+A = A\)，\(A^+AA^+ = A^+\)，\((AA^+)^T = AA^+\)，\((A^+A)^T = A^+A\)。SVD 下有显式：若 \(A = U\Sigma V^T\)，则

$$
\boxed{ A^+ = V\Sigma^+ U^T }
$$

其中 \(\Sigma^+\) 把非零奇异值取倒数再转置。特例：满列秩时 \(A^+ = (A^TA)^{-1}A^T\)；满行秩时 \(A^+ = A^T(AA^T)^{-1}\)。

### 3. 核心推导 / 原理

\(\hat x = A^+b\) 有两层最优性：先在最小二乘意义下使 \(\|Ax - b\|\) 最小（残差正交列空间），再在解集（特解加零空间）中挑范数最小者（只留行空间分量）。\(A^+A\) 是到行空间的正交投影，\(AA^+\) 是到列空间的正交投影。

```text
b = 列空间分量 + 正交余量
↓
AA⁺b 取出列空间分量（投影）
↓
A⁺A 取出行空间坐标（去掉零空间分量）
↓
x̂ = A⁺b：残差最小且自身范数最小
```

### 4. 一个最小例子

\(A = \operatorname{diag}(1, 0)\)，\(b = [2, 3]^T\)。奇异值为 \(1, 0\)，故 \(A^+ = \operatorname{diag}(1, 0)\)，\(\hat x = A^+b = [2, 0]^T\)：第一个分量精确拟合，第二个分量因零奇异值按最小范数取 \(0\)。

### 5. 易错点与理解要点

1. \((AB)^+ = B^+A^+\) 一般不成立（逆的性质丢了）。
2. \(A^+A \ne I\)（除非满列秩）；它是行空间投影。
3. 数值计算要截断微小奇异值，否则取倒后爆炸。
4. 伪逆给最小范数解；若只要任一最小二乘解，正规方程/QR 更便宜。

### 最值得记住的三件事

1. 构造：\(A^+ = V\Sigma^+U^T\)，非零奇异值取倒。
2. 含义：\(\hat x = A^+b\) 残差最小且范数最小。
3. 特例：满列秩 \(A^+ = (A^TA)^{-1}A^T\)。

## 二、快速查阅

### 一句话理解

> 没有逆时最像逆的矩阵：给出最小二乘解里范数最小的那个。

### 核心公式

$$
\boxed{ A^+ = V\Sigma^+ U^T }
$$

$$
\hat x = A^+b
$$

满列秩：\(A^+ = (A^TA)^{-1}A^T\)；满行秩：\(A^+ = A^T(AA^T)^{-1}\)。

### 核心直觉

```text
AA⁺：列空间投影（处理 b）
↓
A⁺A：行空间投影（处理 x）
↓
两头投影夹出唯一最小范数解
```

### 成立条件

- 任意矩阵恒存在唯一；四个 Penrose 条件定义。

### 易错点

- \((AB)^+ \ne B^+A^+\)。
- 小奇异值先截断再取倒。
